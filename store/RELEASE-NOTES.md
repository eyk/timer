Eyk Timer 1.0.0 for Windows x64. German and English follow your Windows language preferences. Up to ten independent countdowns, keyboard shortcut, hourglass countdown and audible/visible alarms. No accounts, ads or analytics. MIT licensed.

Download the EXE below and run it. The installer adds Eyk Timer to the Start menu. This direct download is unsigned, so Windows may show a security warning. Verify its checksum against SHA256SUMS.txt if needed.

Timers are kept only for the current session. During standby, alarms wait until the computer wakes. Windows 10 version 2004 or newer is targeted; validation was performed on Windows 11. Windows 10, real suspend/hibernate and device-specific audio/accessibility behaviour remain manual compatibility checks. Start-menu shortcut creation was verified; immediate Windows-search indexing could not be confirmed in the local test session.
