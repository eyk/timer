# Datenschutzhinweis – Eyk Timer

Entwickler: Walter Seethaler. Stand: 4. November 2026.

Timer arbeitet lokal. Die App übermittelt keine Timer-, Personen- oder Nutzungsdaten an den Entwickler und enthält keine Werbung, Analyse- oder Trackingdienste. Timer werden nur vorübergehend im Arbeitsspeicher gehalten und beim Beenden verworfen. Es gibt weder ein Benutzerkonto noch einen Server für Timerdaten.

Windows und die Microsoft Edge WebView2 Runtime unterliegen zusätzlich den Datenschutzbestimmungen ihrer Anbieter. Bei Installation und Aktualisierung über den Microsoft Store verarbeitet Microsoft Daten nach seinen eigenen Bestimmungen. Ein Besuch von GitHub für Support ist ebenfalls ein separater Dienst.

Kontakt: [GitHub Issues](https://github.com/eyk/timer/issues). Keine persönlichen oder vertraulichen Daten in öffentliche Issues schreiben.
